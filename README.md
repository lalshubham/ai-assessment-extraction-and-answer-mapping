# AI Assessment Extraction & Answer Mapping

## Feature

Upload these files:
1. Question paper (PDF or image)
2. Handwritten answer sheet (PDF or image)

The application would extract the questions from the paper, evaluate the answers, and display them side by side.

When clicked on a question, the corresponding answer will be identified and the **exact region of the answer sheet will be highlighted** along with **grading** and **feedbacks**.

## Highlights

* Upload both files with processing progress.
* Extract questions in the correct printed order.
* Treat sub-questions as separate entries (e.g., `11 (a)` and `11 (b)`).
* Preserve original question numbering.
* Handle questions answered out of order.
* Handle unanswered questions.
* Handle answers that do not match any question.
* Highlight the exact answer region on the answer sheet.
* Support answers spanning multiple pages.
