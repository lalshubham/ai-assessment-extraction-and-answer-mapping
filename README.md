# AI Assessment Extraction & Answer Mapping

## Highlights

Upload these files:
1. Question paper (PDF or image)
2. Handwritten answer sheet (PDF or image)

The application would extract the questions from the paper, evaluate the answers, and display them side by side.

When clicked on a question, the corresponding answer will be identified and the **exact region of the answer sheet will be highlighted** along with **grading** and **feedbacks**.
